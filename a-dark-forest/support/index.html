A Dark Forest / Support

A little help.

Backups, offline play and help with your iPhone game.

Player support

Tell us what happened.

Open support on GitHub

A GitHub account is required. Posts and attachments are public; leave out personal details and private save files.

Keep a separate backup.

Play in landscape. Use Export beside the desired save in the original save selector. Copy the complete save code to a separate private location, and use Import in the selector to restore a compatible code.

Do not remove the app until you have a separate backup. We do not have a server copy of your progress.

Playing offline.

The original game handles its own progression and save rules. iOS can suspend an app in the background; this edition has no developer-operated server or cloud-save service.

Report a problem.

Include the game name, version/build, iPhone model, iOS version, what happened and steps to reproduce. A screenshot can help; check it for personal information before posting.

Edition and availability.

This independent iPhone project preserves the public Godot prototype labelled DEMO 1.4.6. It does not include the separate commercial Steam edition. The iPhone edition is in preparation and is not available to download.
