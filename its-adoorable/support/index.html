It’s a Door: A Love Story / Support

A little help.

Offline play, session behavior and support for your iPhone game.

Report a problem.

Use our public GitHub support tracker. Include the game name, version and build, your iPhone model, iOS version and steps to reproduce the problem. A GitHub account is required. Posts and attachments are public; leave out personal information and private backup files.

Progress and replay.

This one-minute game runs as a live session and is designed to be replayed. It has no original persistent mid-puzzle save. Native web-storage export does not preserve the running puzzle.

The native menu can reload the original game. Where the original game stores data in web storage, you can export or import that data through Files. Import replaces the stored web data after confirmation. These controls cannot turn a game without session saves into a persistent game.

Playing offline.

All gameplay, story and runtime assets are included in the app. No app account is needed. The game does not require an internet connection. External support, original-game and credits links need a connection if you choose to open them.

About this edition.

Independent fan port of it’s a(door)able by Nicky Case, adapted for iPhone touch and safe areas. Open the app’s credits and licenses for the original creator and asset notices.
