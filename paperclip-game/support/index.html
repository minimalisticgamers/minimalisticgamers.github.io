Open support on GitHub

A GitHub account is required. Posts and attachments are public; leave out personal details, sensitive information, and private files.

Keep a separate backup.

In Settings, choose Export save and save the JSON file somewhere you control. Use Import save to restore a compatible host backup. Import asks before replacing progress. Do not remove the app until you have a backup.

The game uses its original save data and a separate local backup. Use Settings → Save now before exporting. The host adds no catch-up production while the app is closed.

Playing offline.

Normal gameplay uses bundled resources. iOS may suspend the game while it is in the background, and the host adds no closed-app catch-up production. External links use your browser.

Reporting a problem.

Include the game name, version/build, device model, iOS version, steps to reproduce, and what you expected. Share a screenshot only if it contains no private information. We do not have a server copy of your save.
