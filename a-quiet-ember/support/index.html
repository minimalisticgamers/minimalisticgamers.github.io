Open an A Quiet Ember support issue

A GitHub account is needed. Support posts and attachments are public. Please leave out personal details, sensitive information, and private save files.

A little context helps.

Include the app version shown in Settings, your device model, iOS or iPadOS version, and the steps that led to the problem. A screenshot can help if it contains no private information.

Keep a separate save.

Use Settings → Save now, then Settings → Export save to keep a native JSON backup in Files. Import it with Settings → Import save. Import replaces the current run, so export the current one first if you want to keep it.

The original game’s save menu uses Base64 save codes. Native JSON backups and game save codes are different formats; use their matching import controls.

Before resetting or reinstalling.

Export a backup first. Progress lives on your device and we do not keep a server copy. We cannot restore a save that has been deleted without a separate backup.

Background play and sound.

The game saves progress, but iOS can suspend it when it is in the background. The app adds no catch-up production while closed. Sound, lighting, and language controls are in Game options.

Privacy and source.

Read the app’s privacy policy for local saves, Apple services, and public support posts. Find the original credits and corresponding iOS source on the source and licenses page.
